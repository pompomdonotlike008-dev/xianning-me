算力中心搞绿电直连，到底能省多少电费？算给你看

2026-07-28算电协同

算电协同喊了半年。34号文定方向，688号文给路径，1192号文算电费。

但双回路供电这个现实约束，让很多账跟纸上算的不一样。本文参数全部取自江西省220kV等级公开电价数据，标注出处，你可以代入自己的参数重算。

一、先搞清楚：绿电直连是怎么省钱的

算力中心的电费账单，传统模式由五笔费用组成：

到户电价 = 上网电价 + 输配电价 + 系统运行费 + 线损费 + 政府基金

走绿电直连后，省钱来自两个方向：

变化一：输配电费可选容量制

绿电直连项目有两种输配电价模式可选——两部制（基本电费+电量电费，全部用电量都交）或容量制（固定月费）。选哪种取决于负载率与省平均负荷率的比较。

变化二：自发自用的电量，免交系统运行费和线损费

这是1192号文最值钱的规则。直联项目的自发自用电量不用交这两笔钱。

但有个关键现实约束：算力中心必须双回路供电。

二、双回路为什么关键

算力中心T3+要求两路独立电源，一主一备。

实际平均负荷 80MW
→ 双回路 2×100MVA 接入
→ 总接入容量 = 200MVA
→ 负载率 = 80 ÷ 200 = 40% —— 不可能超过50%

而江西省110kV+工商业平均负荷率约 46%（来源：1192号文配套参数）。

40% < 46% —— 负载率低于省均值，容量制比两部制更贵。所以双回路算力中心应选两部制，而不是跟风选容量制。

四、把算力中心的全部投资算进去

前面的对比只算了电费，但投资决策看的不是"电费几个月回本"，而是绿电直连让整个项目的IRR提高了多少。

总投资估算

一个新建80MW算力中心，全部投资大致如下（不含IT设备，仅基础设施）：

项目金额（万元）

IT设备投资另算，此处暂不纳入，只看基础设施层面电费节省对回报的影响。

IRR提升

以35亿基础设施投资为例，绿电直连每年多产生6,270万的净现金流，相当于全投资IRR提升约0.5-1.5个百分点（具体取决于收入和税负结构）。

如果PPA能谈到0.28元/kWh，年节省10,194万，IRR提升幅度翻倍。如果IT设备也纳入总投资（60-80亿），IRR提升约0.3-0.8个百分点。

绿电直连不是让算力中心"赚大钱"的决策，而是让算力中心在同等条件下比同行多出0.5-1.5个点的IRR优势。在行业平均IRR普遍8-12%的背景下，1个点的差距可能就是"投"与"不投"的分界线。

八、怎么判断

条件结论
系统运行费 ≥ 0.06 + PPA价差≥0.05元/kWh✅ 经济性显著
系统运行费 ≥ 0.06 + PPA价差<0.03*⚠️ 需精确测算，主要靠制度豁免回本
系统运行费<0.03 + PPA价差<0.03❌ 不建议

* PPA价0.35元/kWh时价差仅0.027元/kWh，属于此档。

① 实际平均负荷 = _____ MW
② 接入容量 = _____ MVA（双回路=单回路容量×2）
③ PPA协议价 = _____ 元/kWh
④ 专线距离 = _____ km

⑥ 年节省 ≈ ⑤×绿电量 + (0.376999-③)×绿电量 + 线损豁免

PPA价差小的时候，输配电费不是节省项，制度豁免（系统运行费+线损）才是基本盘。

PPA电价0.35元/kWh时，年节省6,270万，系统运行费豁免占60%。PPA电价如果能降到0.28元/kWh，年节省就能冲到10,194万。PPA电价每降0.01元，年节省增加约560万。
